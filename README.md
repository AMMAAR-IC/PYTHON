# PYTHON

A collection of standalone Python scripts, grouped by topic.

## MachineLearning/
Supervised, unsupervised and semi-supervised learning — both scikit-learn based
and written from scratch. AdaBoost, DBSCAN, GMM, KNN, KMeans, PCA, Naive Bayes,
Perceptron, SVM, random forests, label spreading, pseudo-labeling, self-training,
and a pure-NumPy neural network with backprop trained on the digits dataset.

## AI_And_Search/
Classic AI: search, constraint solving and reasoning. A* pathfinding, 8-puzzle
heuristics, DFS maze solving, N-Queens, Knight's Tour, Sudoku validation, a SAT
solver, a forward-chaining inference engine, the Einstein riddle, Markov chains.

## Algorithms/
General algorithms and data-structure practice — merge sort, an expression
evaluator, a small regex engine, word break, list/set operations.

## Cryptography/
Encoding, hashing and hiding data — LSB image steganography, Morse code,
modular inverse / extended GCD, DNA-based hash patterns, QR code generation.

## TerminalAnimations/
ASCII art and animated terminal effects — binary rain, black hole, comet, fire,
ice crystals, lightning, DNA helix, magnetic fields, neuron pulses, spirals,
stars, volcano, water ripples, a matrix clock.

## Simulations/
Modelling and generative experiments — the logistic map / chaos plot, infection
spread, an Ulam prime spiral, alien signal entropy analysis, weather generation,
subjective time perception.

## Games/
Interactive terminal games and toys — snake, a maze crawler, Tamagotchi, a text
adventure, virus defense, a typing test, spell casting, maze generation.

## MediaProcessing/
Audio, speech and image work — live sound visualisation, voice transcription,
mood analysis from microphone input, sentiment reactions, image upscaling
(OpenCV and Real-ESRGAN).

## Apps/
Larger self-contained tools — a library management system, task manager, time
capsule, search engine with a Tkinter UI, calculator, Ollama chatbot, window
title classifier, keystroke analytics.
